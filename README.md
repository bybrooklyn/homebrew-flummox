# Flummox Homebrew tap

Install the Apple Silicon desktop app after the first release:

```sh
brew tap bybrooklyn/flummox
brew install --cask flummox
```

Update with `brew upgrade --cask flummox`; remove with `brew uninstall --cask flummox`.

The macOS app currently provides the desktop shell. Compression is not implemented on macOS.

Stable tags in [Flummox](https://github.com/bybrooklyn/flummox) automatically update the checksum-pinned cask here after all release builds and installation checks pass.
